Student Management System in C
A menu-driven Student Management System built using the C programming language.

Features:

Add student records
Display student details
Search for students
Update student information
Delete student records
Save and load student data using file handling
Sort students by marks and find the topper
Calculate average marks
Find highest and lowest marks
Display passed and failed students
Search and filter students based on marks

Technologies Used:

C Programming
Arrays and strings
Functions and control structures
File handling

How to Run:

Download student_management.c.
Open it in a C compiler.
Compile and run the program.

Example using GCC:
gcc student_management.c -o student_management

Run on Windows:

student_management.exe

Purpose:

This project was created to practise C programming, arrays, menu-driven programs, and file handling.
